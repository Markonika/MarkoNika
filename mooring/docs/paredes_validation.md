# Milestone 8: Paredes (2016) free-buoy decay and 3-leg moored buoy

Reference: Paredes (2016), *Study of Mooring Systems for Offshore Wave Energy Converters* (Ch. 5, Tables 5.3-5.14, Figs 5.4, 5.5, 5.21, Annex A).
Configs: `examples/paredes/{free_buoy,con1,con2,cat}.json`, generated by `scripts/make_paredes_configs.py` (every number is annotated with its source).
Run: `build/paredes_report examples/paredes [statics|stiffness|free|decay|all] [con1|con2|cat]`; tests: `tests/test_paredes.cpp`
(fast part in the default suite, the long part as `ctest -R paredes_validation`).

## Model as run
Body: m = 35.5 kg, Icg = 0.87 kg m^2 (roll, pitch), yaw inertia 1.18 (**assumed**), constant potential-theory added mass and radiation damping per
configuration (Tables 5.12-5.14: mab, brb), hydrostatics C33 = rho g pi D^2/4 = 2043.5 N/m, C44 = C55 = 37.76 N m/rad (Table 5.14, free buoy).
Reference pose: free-floating draft 0.176 m. Fairleads 0.2725 m from the axis (D/2 + 0.015 m), 0.180 m above the keel (0.220 m below the top),
legs at 0 / +-120 deg with leg 2 leeward (Fig. 5.5). Anchors at 1.800 m (CON) / 6.660 m (CAT) horizontal distance from the fairlead, 0.02 m
above the floor (anchor plate). Lines: Table 5.9 (polyester: EA = 1.6e5 N, m_l = 3.2e-3 kg/m, gamma_l = 8.0e-3 N/m) and Table 5.10 (chain:
EA = 1.6e6 N, m_l = 0.1447 kg/m, gamma_l = 1.243 N/m). CON1 = one rope per leg of length 0.700 + 1.585 = 2.285 m with the floater at 0.700 m;
CON2 = the same rope with a clumpweight at 1.600 m (0.900 + 0.685 m, Fig. 5.4, the sections add up to the same 2.285 m). CAT = 5.0 m lying + 1.95 m
suspended = 6.95 m (Fig. 5.4; Table 5.6 implies 7.0 m). Floaters and clumpweights from Tables 5.7, 5.8 (point elements, milestone 6).

### Assumptions that are NOT in the thesis (flagged in the generator and here)
* Hydrodynamic coefficients of the lines: Cm = 3.8, Cdt = 0.5, Cdn = 2.5 (Table 3.3, a *chain*), applied to the rope as well; equivalent-mass
  diameters (1.742 mm rope, 4.86 mm chain) following the thesis' own rule for the Chalmers chain.
* Floater drag Cd = 0.5 and clump size 0.04 m with Cd = 1.0; floater and clump added mass Cm = 0.
* Yaw inertia 1.18 kg m^2; soil of the CAT bed (Ks = 3 GPa/m, zeta = 1, mu = 0.3: the Chalmers values); anchor and bed height 0.02 m.
* The (uncoupled) diagonal added-mass/damping model: no surge-pitch coupling, constant coefficients taken at the measured natural
  frequency of each configuration (the thesis could only obtain them there).
* The 1.800 m / 6.660 m anchor distances are taken as horizontal fairlead-to-anchor distances along each leg.
No coefficient was adjusted to improve any comparison below.

## Test 6: free buoy
| Check | Result |
|---|---|
| Heave stiffness rho g pi D^2/4 | 2043.5 N/m (brief: about 2040; thesis K_t = 2039.5) |
| Heave damped period, A33 = 26.92 kg, B33 = 37.92 kg/s | **1.0997 s**; measured 1.112 +- 0.006 s: **-1.1 %** (about 2 sigma); analytic period of the same model 1.1005 s |
| Pitch damped period, I = 0.87 + A55 (0.283), B55 = 0.0493, C55 = 37.76 | **1.0979 s**; measured 1.170 +- 0.005 s: **-6.2 %** (**known disagreement**) |
The simulated periods equal the closed form of the same oscillator to < 1e-3 (verification), so the disagreements are model/input, not numerics.

Pitch disagreement, not resolved: the thesis' own total inertia from the decay test (m_t = 1.31 kg m^2, Table 5.14) reproduces 1.170 s, but that is how
that number was derived, not a prediction. Table 5.3 states Icg excludes fixtures and adapters (m_t - A55 = 1.03 kg m^2 vs 0.87). Hypotheses
(**untested**; no BEM data to check them): (i) fixtures/instrumentation; (ii) the coupled surge-pitch added mass of a buoy pitching about a CG
0.100 m below the waterline, about z^2 A11 = 0.18 kg m^2, which would give I = 1.34 and T = 1.18 s (printed by the test as a diagnostic, used nowhere).
Heave: the thesis' potential-theory mass and damping (A33 = 26.92, B33 = 37.92) were used; with the experimentally estimated total damping (54.67 kg/s)
the period would change by < 0.3 % (not used; it is not a prediction).

**Statics** (equilibrium by Newton on the 6-DOF residual; no tuning). Leg tension at the fairlead vs Table 5.5 (+-0.2 N) and draft change vs Table 5.4:

**Surge secant stiffness** K(x) = -(F_x(x) - F_x(0))/x, surge held, all other DOF free. The single values of Table 5.12 (28.65, 28.28, 23.63 N/m) carry no
displacement; the curves of Fig. 5.21 do (read by eye, +-1.5 N/m):

|---|---|---|---|
| -0.10 | 25.1 / ~31 (-19 %) | 28.0 / ~28.8 (-3 %) | 33.9 / ~37.5 (-10 %) |
| +0.10 | 25.2 / ~30 (-16 %) | 26.2 / ~25.8 (+1 %) | 20.4 / ~22.0 (-7 %) |
| +0.20 | 25.9 / ~30.6 (-15 %) | 26.6 / ~26.8 (-1 %) | 22.9 / ~25.0 (-8 %) |
CON2 agrees with the measured curve; the CAT chain reproduces the measured U-shaped curve (minimum near +0.1 m) about 8-10 % low; **CON1 is 15-19 % low**

stiffness (+-1 deg): model 1.19 / 0.54 / 0.25 vs 1.44 / 1.84 / 0.84 N m/rad (the pitch values disagree by up to a factor 3.4 for CON2/CAT, not understood).

### CON1 sensitivity (diagnostic; nothing adopted)
The stiffness is very sensitive to the rope length, which the data cannot resolve (pretension is given to +-0.2 N):

| variant | pretension [N] | K(-0.1, +0.1, +0.2) [N/m] |
|---|---|---|
| baseline: s_f = 0.700, L = 2.285 m | 2.75 | 25.1, 25.2, 25.9 |
| rope 35 mm shorter (L = 2.25 m) | 3.25 | 29.2, 28.4, 29.5 |
| cable ends at the sphere surface, one side (s_f = 0.7675, L = 2.3525 m) | 2.69 | 19.7, 20.8, 21.2 |
| both sides (L = 2.42 m) | 1.31 | 17.2, 18.3, 15.1 |
A 1.5 % change of the rope length moves K by 13 % and the pretension by 18 %, so a 10-15 % stiffness disagreement is within the geometric uncertainty
of the as-built model. The drawing (Fig. 5.4) also shows the floater about 0.11 m below the surface, whereas the labelled lengths put it deeper.
